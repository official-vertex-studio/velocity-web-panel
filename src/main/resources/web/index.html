API quick start

Versioned REST API · JSON responses
Base URL/api/v1
HealthGET /health
PlayersGET /players
ServersGET /servers
AnalyticsGET /analytics
Node.js (fetch)
const r = await fetch(`${PANEL_URL}/api/v1/players`, { headers: { Authorization: `Bearer ${process.env.VERTEX_API_KEY}` } });
if (!r.ok) throw new Error(`Vertex API: ${r.status}`);
const players = await r.json();
Python (requests)
import os, requests
r = requests.get(os.environ["VERTEX_URL"] + "/api/v1/servers", headers={"Authorization": "Bearer " + os.environ["VERTEX_API_KEY"]}, timeout=5)
r.raise_for_status()
servers = r.json()
cURL
curl -H "Authorization: Bearer $VERTEX_API_KEY" "$VERTEX_URL/api/v1/stats"
Full endpoint reference and SDK examples are included in docs/API.md and docs/SDK_EXAMPLES.md in the source ZIP.
