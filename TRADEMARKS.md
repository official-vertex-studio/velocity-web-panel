# Trademark and Branding Policy

This policy concerns the names, logos, and branding associated with Vertex Studio
and Vertex Velocity Web Panel. It is separate from the software license.

## Software license versus branding

The project source code is licensed under GNU GPL-3.0, as described in `LICENSE`.
That license grants permissions for the covered code subject to its terms. It does
not automatically grant permission to use Vertex Studio's name, logo, or other
branding to imply that a modified or redistributed version is an official release.

## Use of the project name

- You may refer to Vertex Velocity Web Panel to accurately identify the upstream
  project when discussing it, giving attribution, or explaining compatibility.
- Do not state or imply that an unofficial fork, modified build, or redistributed
  copy is published, endorsed, supported, or maintained by Vertex Studio unless
  that is actually authorized.
- If you distribute a modified fork, identify it clearly as an unofficial fork,
  use a distinct product name and visual identity, and retain notices required by
  the applicable software license.
- Do not use Vertex Studio logos or artwork in a way that falsely suggests
  affiliation or endorsement.
